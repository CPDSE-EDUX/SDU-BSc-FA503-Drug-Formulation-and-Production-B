# Lab exercise: Dissolution testing

Data analysis guide for the dissolution lab exercise. Ibuprofen tablets are tested in 900 mL dissolution medium, and samples are taken at set time points. The guide contains the complete code.

R: conversion of absorbance to concentration with a calibration curve, cumulative release with correction for sample removal, mean and SD per time point, dissolution profiles in mg and % of dose, and an optional Weibull fit.

## Files

| File | Description |
|------|-------------|
