# Lab exercise: Uniformity of dosage units

Data analysis guide for the uniformity of dosage units test (Ph. Eur. 2.9.40). Students have made hard capsules with ibuprofen and check whether the batch meets the acceptance criteria. The guide has code blanks for students to fill in.

R: ibuprofen content per mg of powder from a UV assay, content and % of label claim for each capsule, and the acceptance value (AV) for stage 1 (10 capsules) and stage 2 (30 capsules).
