# Exercise class: Sieve analysis

Problem-solving class where students analyse the particle size distribution of a powder from a sieve analysis. Example data are entered directly in the guide. The guide has code blanks for students to fill in.

R: size intervals, relative and cumulative frequency, and frequency density, a histogram of the mass retained on each sieve, a cumulative frequency curve, and D10, D50 and D90. The powder is then classified by fineness using Ph. Eur. 2.9.35.
